# Contributing to MXPL

Please open an issue before a large change. Include the `.mx` program or QEMU command that reproduces a bug, the expected behavior, and the observed output.

For a code change:

1. Run `bash compile.sh main.mx`.
2. Run `bash scripts/test.sh`.
3. Keep the compiler, runtime, examples, and documentation consistent.

The repository has no chosen open-source license yet. Discuss contribution and licensing terms with the project owner before submitting code for publication.
