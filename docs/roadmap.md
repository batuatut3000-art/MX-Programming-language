# Roadmap

- Keep `compile.sh` and the example programs buildable in CI.
- Improve UEFI HTTPS diagnostics and compatibility while preserving certificate verification.
- Expand HTML, CSS, and JavaScript support; the current browser cannot run complex sites such as Chess.com.
- Add more firmware-supported network and input devices, then test on physical UEFI hardware.
- Consider a separate kernel only after defining storage, memory, process, and driver interfaces.
